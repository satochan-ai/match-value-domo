# MatchValue ⚡

🌐 **Live Demo (プレビュー):** [https://satochan-ai.github.io/match-value-domo/src/index.html](https://satochan-ai.github.io/match-value-domo/src/index.html)

MatchValueは、エンジニアのスキルシートからSES市場における「市場価値スコア」「想定単価」「提案のしやすさ」などを自動分析する営業支援ツールです。
営業担当者がスキルシートを読み込むだけで、技術的な強みや懸念点、クライアント向けのアピール文を瞬時に生成し、営業活動を強力にサポートします。

## 🌟 主な機能

* **スキルシートの自動解析**
  * テキストの直接入力のほか、ファイルの添付（`.txt`, `.pdf`, `.docx`, `.xlsx`, `.csv`）にも対応しています。
* **市場価値のスコアリング・判定**
  * 技術力・工程経験・市場適合性などの多角的な観点から100点満点でスコアリング。
  * スコアに基づく「提案判定」と「書類通過率の目安」を表示します。
* **想定単価・年収換算シミュレーション**
  * 算出されたスキルレベルからSES市場における適正な単価レンジ（万円/月）を提示。
  * その単価ベースでの「フリーランス想定年収」「手取り目安」「会社員換算年収」を自動計算します。
* **単価妥当性の判定**
  * エンジニアの「希望単価」と「市場想定単価」を比較し、市場感とズレがないか（高い・適正・安い）をアラート表示します。
* **強み・懸念点の言語化**
  * 検出されたスキルや経験工程から、営業時に武器となる強みや、面談で突っ込まれやすい懸念点を整理します。
* **営業コメント・BP配信文の自動生成**
  * クライアントへの提案文や、パートナー（BP）企業向けの案件照会文をワンクリックで生成し、そのままコピーして利用可能です。
* **マルチデバイス対応（レスポンシブ）**
  * 外出中や移動中でもスマホから片手で操作しやすいUI設計になっています。

## 💻 技術スタック

* HTML5 / CSS3 (Vanilla)
* JavaScript (ES6)
* ライブラリ (CDN経由)
  * [PDF.js](https://mozilla.github.io/pdf.js/) (PDF読み込み)
  * [Mammoth.js](https://github.com/mwilliamson/mammoth.js) (Word読み込み)
  * [SheetJS](https://sheetjs.com/) (Excel/CSV読み込み)

※ バックエンドサーバーやデータベースを持たない完全な静的（フロントエンドのみ）なSPA構成です。

## 🚀 使い方（セットアップ不要）

本アプリケーションはビルドが不要な構成となっているため、環境構築なしですぐに動かせます。

### ローカルでの実行
1. リポジトリをクローンまたはダウンロードします。
2. `src/index.html` をお使いのWebブラウザ（Chrome推奨）で開くだけで動作します。

### Webホスティング（GitHub Pages 等）
本リポジトリの `main` ブランチを GitHub Pages 等の静的ホスティングサービスに連携するだけで、全世界に公開（デプロイ）可能です。

## 📁 ディレクトリ構成

```text
match-value/
├── src/
│   ├── index.html        # メイン画面 (UI)
│   ├── css/
│   │   └── style.css     # スタイルシート（レスポンシブ対応）
│   └── js/
│       ├── app.js        # エントリーポイント・イベント制御
│       ├── fileReader.js # ファイルのパース (PDF/Word/Excel)
│       ├── parser.js     # スキルシートのテキスト解析
│       ├── scorer.js     # スコア・単価算出ロジック
│       ├── judge.js      # 判定・強み/懸念点の抽出
│       ├── generator.js  # 営業コメントの生成
│       ├── renderer.js   # 画面描画 (DOM操作)
│       └── sampleData.js # テスト用のサンプルデータ
└── docs/                 # 仕様書・設計書などのドキュメント類
```
