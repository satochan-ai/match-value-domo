# MatchValue スコアリングロジック定義（MVP）

## 1. 概要

本ドキュメントは、スキルシートから市場価値スコア（0〜100点）を算出するためのロジックを定義する。

---

## 2. スコア構成

合計：100点

| 項目    | 配点 |
| ----- | -- |
| 技術力   | 25 |
| 工程経験  | 15 |
| 上流経験  | 10 |
| 希少性   | 15 |
| 市場適合性 | 15 |
| 条件適合  | 10 |
| シート品質 | 10 |

---

## 3. 技術力（最大25点）

### 経験年数ベース

| 年数   | 点数 |
| ---- | -- |
| 1年未満 | 3  |
| 1〜2年 | 8  |
| 3〜4年 | 12 |
| 5〜7年 | 18 |
| 8年以上 | 22 |

### スキル加点

* Java / Python / JavaScript → +2点
* React / Vue / Angular → +2点
* Spring / Django / Node → +2点

※最大25点で打ち止め

---

## 4. 工程経験（最大15点）

| 工程         | 点数 |
| ---------- | -- |
| テストのみ      | 3  |
| 製造（コーディング） | 6  |
| 詳細設計       | 10 |
| 基本設計       | 13 |
| 要件定義       | 15 |

※複数ある場合は最高工程を採用

---

## 5. 上流経験（最大10点）

* 要件定義あり → +5点
* 顧客折衝あり → +3点
* リーダー経験あり → +2点

---

## 6. 希少性（最大15点）

* AWS / GCP / Azure → +5点
* AI / データ系 → +5点
* SAP / Salesforce → +5点

---

## 7. 市場適合性（最大15点）

* Java / Web系 → +10点
* フロント（Reactなど） → +8点
* インフラ（クラウド） → +8点
* ニッチ技術 → +3点

---

## 8. 条件適合（最大10点）

* フルリモートのみ → -3点
* 単価が市場より高い → -3点
* 外国籍（日本語ビジネス未満） → -4点

※減点方式（最低0点）

---

## 9. シート品質（最大10点）

* 見やすい（箇条書き） → +5点
* プロジェクト詳細あり → +5点

---

## 10. 判定ロジック

| スコア    | 判定     |
| ------ | ------ |
| 80〜100 | 即提案    |
| 60〜79  | 条件付き提案 |
| 0〜59   | 見送り    |

---

## 11. 書類通過率

```txt
通過率 = スコア × 0.8
```

例：
80点 → 64%

---

## 12. 単価レンジ算出

```txt
ベース単価 = 技術力 × 2.5
```

補正：

* 上流経験あり → +5万
* クラウドあり → +5万
* 条件厳しい → -5万

---

## 13. 出力ロジック（簡易）

### 強み

* スコアが高い項目を抽出

### 懸念点

* スコアが低い項目を抽出

### 改善ポイント

* 減点要素をそのまま改善提案に変換
